For this lab, I used ChatGPT to help with the C++ code, review the requirements, and write the explanations and documentation. I used OnlineGDB to compile and test the two programs. I wanted to make sure I had both the correct answers and the code style the assignment asked for.

One decision I made was to keep calculations separate from cout statements. I also kept the ocean rise rate as a named constant because it stays the same during a run.

To check the programs, I compared the output with the math. The five original values added to 154 and gave an average of 30.8. When I changed them to 1, 2, 3, 4, and 7, the average was 3.4. For the ocean program, the original rate gave 7.5, 10.5, and 15 millimeters. Changing the rate to 2.3 gave 11.5, 16.1, and 23 millimeters. The results matched, and I put the original values back before the final runs.
